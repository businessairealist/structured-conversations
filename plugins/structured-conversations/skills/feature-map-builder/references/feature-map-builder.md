# Feature Map Builder

Break a feature into actors, rules, examples, steps, outcomes, and unresolved questions.

## Use When

- a feature needs a structured requirements conversation before acceptance criteria are finalized
- a rule/example board exists but the team needs a more feature-oriented summary
- several actors or consequences need to be kept visible in one artifact

## Good Inputs

- feature name
- actor list
- business rules
- examples or scenarios
- main steps and expected outcomes

## Build Workflow

1. capture the feature slice being discussed
2. list the actors involved
3. separate business rules from examples and implementation steps
4. record outcomes and unanswered questions

## Good Output Characteristics

- one feature focus instead of a mixed backlog dump
- rules and examples are easy to scan
- steps stay at the behavior level
- unresolved questions are explicit enough to drive follow-up work
