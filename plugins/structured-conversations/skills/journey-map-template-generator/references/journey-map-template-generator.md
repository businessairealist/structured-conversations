# Journey Map Template Generator

Generate a reusable customer-journey canvas with stage-based structure.

## Use When

- a workshop needs a blank or lightly example-filled journey board
- the team wants a reusable canvas across projects
- stage-based discussion should start before evidence is added

## Good Output Characteristics

- clear stage structure
- reusable row layout
- optional example rows clearly marked as examples
- aligned with journey facilitation and builder workflows
