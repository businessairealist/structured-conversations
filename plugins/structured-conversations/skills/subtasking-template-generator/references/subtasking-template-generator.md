# Subtasking Template Generator

Generate a reusable board for subtasking sessions.

## Default Sections

1. current code review
2. code modification discussion and ideas
3. sequence diagram or interaction flow
4. implementation subtasks

## Good Template Characteristics

- each section includes a short prompt
- the board can be reused without project-specific assumptions
- the structure matches the subtasking workshop flow
- it leaves room for dependencies, handoffs, and open questions
