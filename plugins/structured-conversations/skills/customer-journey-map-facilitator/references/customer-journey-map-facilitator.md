# Customer Journey Map Facilitator

Generate a workshop-ready customer-journey board with stage-based prompts.

## Use When

- the team needs a live journey-mapping session
- the output should capture current-state evidence first
- stage-by-stage discussion is more useful than a direct artifact build

## Good Inputs

- persona
- session goal
- participant list
- custom journey stages when needed

## Good Output Characteristics

- stage-based prompts
- visible evidence capture
- friction and idea capture by stage
- ready for later journey analysis
