# Subtasking Workshop Facilitator

Facilitate the four-part subtasking workflow and capture the outcome in a reusable board artifact.

## Workshop Stages

1. current code review
2. code modification discussion and ideas
3. sequence diagram or interaction flow
4. implementation subtasks

## Facilitation Goals

- surface the real implementation risks
- keep technical sequence visible before splitting into tasks
- turn discussion into actionable subtasks
- preserve open questions and dependencies
