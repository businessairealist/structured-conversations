# Journey To Priority Translator

Translate a completed customer journey map into prioritized improvement candidates.

## Use When

- the journey map is complete enough to reason about friction
- the team needs a ranked improvement starting point
- journey understanding should feed backlog or roadmap shaping

## Good Inputs

- completed customer-journey-map artifact
- specific artifact id or slug when multiple journey maps exist

## Good Output Characteristics

- ranked improvement candidates
- clear traceability to journey evidence
- strong emphasis on friction-heavy stages
- explicit open questions where more validation is needed
