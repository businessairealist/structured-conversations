# Pitch Comparison Matrix Builder

Compare multiple pitch variants side by side so teams can evaluate resonance and clarity.

## Use When

- there are multiple pitch variants to compare
- teams want one artifact for wording and resonance review
- pitch selection should be visible instead of discussed from memory

## Good Inputs

- labeled pitch variants
- optional audience or persona context
- optional evaluation notes

## Good Output Characteristics

- uses one normalized row structure
- makes differences between variants easy to scan
- preserves full pitch statements as well as row-by-row comparisons
- produces a canonical vision output package
