# Process Waste Classifier

Classify mapped waste patterns so improvement discussions can focus on concrete waste categories.

## Use When

- the process has visible bottlenecks or rework
- the team wants a categorized waste view
- improvement work needs clearer problem labels

## Good Inputs

- process steps
- issue, bottleneck, delay, or rework notes
- optional owner or handoff notes

## Good Output Characteristics

- classifies waste into clear categories
- ties each category back to concrete steps
- keeps evidence text visible
- produces a canonical diagnostic output package
