# Flow Efficiency Calculator

Calculate work time, wait time, lead time, and total flow efficiency for a mapped process.

## Use When

- a value stream or process map already exists
- work versus wait time should be quantified
- improvement conversations need a baseline efficiency metric

## Good Inputs

- ordered steps
- work time per step
- wait time per step

## Good Output Characteristics

- totals work, wait, and lead time
- shows per-step timing
- calculates overall flow efficiency
- produces a canonical diagnostic output package
