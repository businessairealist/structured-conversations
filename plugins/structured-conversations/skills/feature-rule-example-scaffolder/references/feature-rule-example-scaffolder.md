# Feature Rule Example Scaffolder Reference

Use this skill when the team needs a feature-mapping style board that connects:

- features
- actors
- business rules
- examples
- steps
- consequences or outcomes
- questions

The rendered board should follow the visual logic of the Feature Mapping canvas:

- one guide panel on the left
- consistent column labels
- card-like cells with short, scannable text
- questions preserved as unresolved prompts rather than hidden assumptions
