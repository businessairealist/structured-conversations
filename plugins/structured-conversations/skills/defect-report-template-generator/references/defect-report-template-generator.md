# Defect Report Template Generator

Generate a reusable defect report template with the fields needed for reproducible, severity-aware bug reports.

## Required Fields

- summary
- impact
- environment
- version
- steps to reproduce
- expected behavior
- actual behavior
- evidence
- severity
- priority
- open questions

## Output Characteristics

- consistent across defect reports
- compatible with context capture and reproduction artifacts
- ready for issue tracker or handoff workflows
