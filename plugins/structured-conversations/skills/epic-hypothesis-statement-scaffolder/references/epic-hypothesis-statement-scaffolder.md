# Epic Hypothesis Statement Scaffolder

Scaffold a first-pass epic hypothesis statement from the standard fields.

## Use When

- the team has partial epic inputs and needs structure
- a reusable first draft is needed before the final epic statement is polished
- missing fields should become prompts instead of silent blanks

## Good Inputs

- epic name or context
- any known owner, description, outcomes, OKR, indicators, or NFR

## Good Output Characteristics

- includes every standard epic field
- uses clear fill-in prompts for missing values
- reads like a coherent first draft
- stays compatible with the final epic writer
