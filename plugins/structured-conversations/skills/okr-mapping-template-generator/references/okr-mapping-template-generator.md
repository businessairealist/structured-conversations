# OKR Mapping Template Generator

Generate a reusable scaffold for objective, key-result, and initiative mapping.

## Use When

- teams want a repeatable OKR board structure
- strategy workshops need a blank canonical map before content is known
- the repo should provide a reusable OKR template, not only populated examples

## Good Inputs

- template title or context
- objective prompt
- key result prompts
- initiative prompts
- alignment notes or reminders

## Good Output Characteristics

- clearly separates objective, key results, and initiatives
- emphasizes measurable outcomes
- stays simple enough to reuse in workshops
- produces a real structured output package
