# Story Subtask Planner

Break a story into actionable work after the story is ready enough for implementation planning.

## Workshop Flow

1. Review current code and adjacent behavior.
2. Discuss likely code modifications and options.
3. Sketch the interaction or sequence flow.
4. Break work into functional subtasks with dependencies.

## Preferred Subtask Categories

- frontend
- backend or service
- data or persistence
- integration
- testing
- deployment or operations when needed
