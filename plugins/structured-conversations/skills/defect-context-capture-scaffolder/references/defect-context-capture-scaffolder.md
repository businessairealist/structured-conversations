# Defect Context Capture Scaffolder

Capture the environment, system, version, observed behavior, and triage questions needed before a defect is routed.

## Use When

- a failure is known but the environment or evidence is incomplete
- the team needs enough context to reproduce, prioritize, or assign ownership
- a defect report should not be written until key details are explicit

## Output Characteristics

- environment, system, version, and observed behavior are separated
- triage prompts identify missing evidence
- artifact can feed defect report and reproduction skills
