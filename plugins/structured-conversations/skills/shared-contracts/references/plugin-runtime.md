# Plugin Runtime

This shared reference describes the common runtime expectations for plugin scripts.

## Runtime Expectations

- scripts should resolve the workspace root consistently
- structured outputs should be registered with execution records
- input and output paths should remain traceable
- user-facing language should emphasize goals, evidence, maps, examples, and next steps rather than raw runtime jargon

## Good Output Characteristics

- reusable across plugin lanes
- consistent artifact packaging
- predictable runtime behavior
- user-facing discovery that prefers likely existing content before asking for uploads
- clear, human-friendly review surfaces and next-step guidance
- summaries and prompts that describe drafts, maps, plans, reports, and scenarios in plain language while keeping system metadata intact behind the scenes
