# Example Map Facilitator

Facilitate an example-mapping session around a story, its rules, example scenarios, and open questions.

## Use When

- the team wants a workshop artifact instead of static notes
- rules are known but examples are still weak or incomplete
- open questions need to be captured while conversation is happening

## Facilitation Prompts

- Which rule still lacks a concrete example?
- Which edge case should become a negative example?
- Which question blocks confident implementation?

## Good Output Characteristics

- the story stays visible at the top of the artifact
- rules and examples are easy to pair mentally
- unresolved questions become follow-up work instead of disappearing
