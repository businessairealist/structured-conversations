# Elevator Pitch Template Generator

Generate a reusable blank elevator-pitch matrix with audience columns and prompt text.

## Use When

- teams want the standard elevator-pitch canvas before writing content
- workshops need a reusable audience-by-audience pitch matrix
- the repo should provide a canonical pitch template, not only completed pitches

## Good Inputs

- template title
- audience column labels
- row prompt overrides

## Good Output Characteristics

- preserves the standard pitch row order
- uses prompt-based audience cells
- keeps the final synthesized pitch visible
- produces a canonical vision output package
