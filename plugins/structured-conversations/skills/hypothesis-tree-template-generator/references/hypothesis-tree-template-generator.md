# Hypothesis Tree Template Generator

Generate a reusable scaffold for observation-to-hypothesis-to-experiment strategy work.

## Use When

- teams need a repeatable hypothesis-tree format
- strategy workshops need structure before specific branches are known
- the repo should offer a canonical template, not just filled examples

## Good Inputs

- template title or context
- optional branch names
- prompts for observations, hypotheses, experiments, signals, and decisions

## Good Output Characteristics

- includes observation, hypothesis, experiment, signal, and decision sections
- encourages multiple alternative branches
- stays easy to adapt to different problems
- produces a real structured output, not just a loose note
