# Hamburger Method Guide

Apply the hamburger method when a story should ship in thin, progressively richer layers.

## Use When

- the team wants the smallest end-to-end path first
- quality improvements should be layered after the thin path
- a large story needs to be split without losing customer value

## Good Output Characteristics

- a thin happy-path slice
- a validation or guardrail layer
- a richer follow-on layer
