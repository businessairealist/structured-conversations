# Goal Oriented Roadmap Template Generator

Generate a reusable Now/Next/Later roadmap canvas with outcome and customer-needs structure.

## Use When

- a team needs a blank roadmap canvas
- the structure should be reusable across projects
- horizon-based planning should start before real bets are added

## Good Output Characteristics

- visible goal area
- clear Now, Next, and Later columns
- outcomes and customer-needs panels
- optional example cards clearly marked as examples
