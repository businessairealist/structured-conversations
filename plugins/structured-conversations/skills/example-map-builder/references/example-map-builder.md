# Example Map Builder

Convert a story and its rules into an example map that clarifies behavior before implementation.

## Use When

- the story already has acceptance criteria or known rules
- the team needs concrete examples before writing scenarios
- exception handling or policy questions still need to be surfaced explicitly

## Good Inputs

- story text
- acceptance criteria artifacts
- feature-map or rule notes
- policy thresholds or exception rules

## Build Workflow

1. load the story and rule set
2. convert rules into concrete examples
3. add negative or validation examples where needed
4. capture unresolved questions

## Good Output Characteristics

- clear separation of rules, examples, and questions
- examples grounded in observable behavior
- traceability to the acceptance criteria
- enough clarity for downstream Gherkin writing
