# User Story Formats

## Traditional

`As a <user>, I want to <goal>, so that <benefit>.`

## Hypothesis Driven Development (HDD)

`We believe that <capability> will result in <outcome>. We will know we have succeeded when <signal>.`

## Feature Driven Development (FDD)

`<Action> the <result> by <for/of/to/on/from/in> an <object>.`

## Job Story

`When <situation>, I want to <motivation>, so I can <expected outcome>.`

## Jobs To Be Done (JTBD)

`<situation> + <target customer> + <motivation/job> + <desired outcome>.`
