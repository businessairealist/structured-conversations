# INVEST Readiness Checker

Use this reference for criterion-by-criterion story review.

## Criteria

- Independent
- Negotiable
- Valuable
- Estimable
- Small
- Testable

## Review Pattern

1. Read the story and any immediate supporting detail.
2. Assess each criterion with evidence.
3. Separate rewrite advice from split advice and spike advice.
4. Record whether the story looks ready for example mapping or subtasking.
