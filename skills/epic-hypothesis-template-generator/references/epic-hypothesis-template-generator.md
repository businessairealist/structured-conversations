# Epic Hypothesis Template Generator

Generate a reusable blank epic-hypothesis statement that teams can fill in consistently.

## Use When

- teams want the epic statement structure before content is ready
- specification workshops need a standard epic hypothesis template
- the repo should provide a reusable canonical form, not only completed examples

## Good Inputs

- template title
- prompts for each epic-hypothesis field

## Good Output Characteristics

- includes all standard epic-hypothesis fields
- keeps the language prompt-oriented instead of final
- stays easy to reuse in planning sessions
- produces a canonical specification output package
