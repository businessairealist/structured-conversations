# Future Press Release Template Generator

Generate a reusable blank future press release using one of the supported working-backwards structures.

## Use When

- teams want a canonical press-release template before writing the narrative
- working-backwards workshops need a reusable structure
- the repo should provide reusable options, not only finished press releases

## Good Inputs

- template title
- selected structure option
- optional section prompt overrides

## Good Output Characteristics

- preserves one supported section order
- uses prompts instead of finished release copy
- stays easy to reuse across product concepts
- produces a canonical vision output package
