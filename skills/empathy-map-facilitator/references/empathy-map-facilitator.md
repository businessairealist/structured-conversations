# Empathy Map Facilitator

Generate a workshop-ready empathy-map board for one actor.

## Use When

- the goal is collaborative evidence gathering
- a facilitator needs structure and prompts
- the team wants a reusable workshop artifact instead of a finished map

## Good Inputs

- actor or persona
- session goal
- participant list

## Good Output Characteristics

- evidence-first prompts
- explicit inference handling
- one actor per board
- ready for later insight extraction
