# User Story Format Selector

Use this reference to choose among Traditional, HDD, FDD, Job Story, and JTBD framing.

## Selection Heuristics

- Prefer Traditional when actor, goal, and benefit are already clear.
- Prefer HDD when the work is about a capability and a measurable signal.
- Prefer FDD when the team needs action-result framing around a feature behavior.
- Prefer Job Story when situation and motivation matter more than persona labeling.
- Prefer JTBD when the story should focus on context, target customer, job, and desired outcome.

## Recommended Output

Record:

- source context
- compared formats
- selected format
- drafted story
- assumptions and open questions

When rendered, prefer a comparison matrix that mirrors the sample board: one row per format with syntax, example or draft, and readiness cues.
