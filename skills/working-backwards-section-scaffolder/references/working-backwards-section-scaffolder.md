# Working Backwards Section Scaffolder

Scaffold a reusable working-backwards package that combines a future press release with FAQ prompts.

## Use When

- teams want the full working-backwards package structure before writing polished content
- workshops need a blank but canonical press-release-plus-FAQ package
- assumptions should surface early through reusable FAQ prompts

## Good Inputs

- product or concept title
- chosen press-release structure option
- optional FAQ prompts or emphasis areas

## Good Output Characteristics

- includes a complete press-release section set
- includes reusable FAQ prompts
- keeps prompts future-state and customer-centered
- produces a canonical vision output package
