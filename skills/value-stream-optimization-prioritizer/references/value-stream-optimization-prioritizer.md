# Value Stream Optimization Prioritizer

Rank value-stream improvement options by likely effect on flow and waste reduction.

## Use When

- a value stream has already surfaced waste and bottlenecks
- the team wants ranked improvement candidates
- prioritization should be reasoned from flow, waste, and effort

## Good Inputs

- current-state value stream map or step timing data
- improvement candidates
- waste and bottleneck evidence
- optional effort notes

## Good Output Characteristics

- ranked optimization list
- reasoning by bottleneck, waste, and flow effect
- keeps effort tradeoffs visible
- produces a canonical planning output package
