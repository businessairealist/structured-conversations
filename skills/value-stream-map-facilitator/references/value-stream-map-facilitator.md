# Value Stream Map Facilitator

Facilitate a value-stream mapping session from start and end points through future-state discussion.

## Use When

- the team needs a workshop-ready value stream map
- step timing and waste need to be discussed live
- future-state improvement ideas should stay visible without becoming commitments

## Good Inputs

- process title
- start and end points
- optional draft steps
- owner, timing, and issue notes

## Good Output Characteristics

- workshop-ready current-state map
- visible timing, waste, and bottleneck prompts
- future-state questions remain explicit
- produces a canonical mapping output package
