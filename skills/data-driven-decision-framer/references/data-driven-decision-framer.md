# Data Driven Decision Framer

Turn experiment outcomes into pre-committed decisions so evidence collection leads to action.

## Use When

- the team knows what data it wants but not what decision it will make from it
- experiment plans exist without clear next-step logic
- a strategy artifact should capture action for pass, mixed, and fail outcomes

## Good Inputs

- decision question
- experiment or evidence source
- measurable signals
- pass, mixed, and fail conditions
- action for each outcome path

## Good Output Characteristics

- the decision question is explicit
- each evidence path has a concrete next action
- ambiguous outcomes are handled intentionally
- assumptions and risks stay visible
