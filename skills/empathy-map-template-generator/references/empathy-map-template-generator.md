# Empathy Map Template Generator

Generate a reusable empathy-map canvas with prompt cards for each section.

## Use When

- the team needs a blank empathy board
- a workshop needs a reusable canvas before evidence is collected
- a lightweight example-filled template is more useful than an empty board

## Good Output Characteristics

- one prompt per empathy section
- optional example cards clearly marked as examples
- reusable across teams and projects
- aligned with the empathy workshop and builder flow
