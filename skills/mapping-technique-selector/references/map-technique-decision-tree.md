# Map Technique Decision Tree

## Purpose

Use this reference as a quick guide for choosing among the main mapping techniques in the collection.

## Quick Routing Guide

### Choose an empathy map

Use when the problem is understanding what a person sees, hears, says, does, thinks, or feels.

Best for:

- persona understanding
- research synthesis
- pain and gain discovery

### Choose a customer journey map

Use when the problem is understanding stages across an end-to-end experience.

Best for:

- multi-step experiences
- pain points across stages
- opportunity finding across a journey

### Choose an impact map

Use when the problem is connecting a goal to actors, impacts, and deliverables.

Best for:

- outcome alignment
- prioritization around a business goal
- connecting work to effects

### Choose an opportunity-solution tree

Use when the problem is exploring branches from an outcome to opportunities, solutions, and experiments.

Best for:

- discovery branching
- solution exploration
- experiment planning

### Choose a value stream map

Use when the problem is flow efficiency, handoffs, wait time, bottlenecks, or waste in a process.

Best for:

- operational process analysis
- service delivery flow
- internal system handoff analysis

### Choose a user story map

Use when the problem is organizing activities, tasks, stories, and release slices around a user goal.

Best for:

- backlog organization
- release slicing
- end-to-end product workflow planning

### Choose a feature map

Use when the problem is clarifying a feature through actors, rules, examples, steps, and consequences.

Best for:

- feature clarification
- acceptance-criteria preparation
- requirement deepening

### Choose an example map

Use when the problem is clarifying a story through rules, examples, and open questions.

Best for:

- requirement ambiguity
- concrete example discovery
- Gherkin preparation

## Good End State

The chosen technique is strong when the team can immediately see what artifact to create next and why that artifact will reduce the current confusion.
