# Value Stream Map Builder

Map an internal delivery or service process end to end, including steps, owners, work time, wait time, bottlenecks, and waste notes.

## Use When

- the team needs a current-state value stream map
- work and wait time should be visible by step
- bottlenecks and rework loops should be discussed from one artifact

## Good Inputs

- ordered process steps
- owners
- work time and wait time
- bottleneck, waste, or rework notes

## Good Output Characteristics

- shows the flow end to end
- makes time and handoff information visible
- keeps bottlenecks and waste explicit
- produces a canonical mapping output package
