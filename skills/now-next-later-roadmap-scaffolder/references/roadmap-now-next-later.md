# Roadmap Now Next Later

Use horizon-based roadmap structure instead of date-driven feature promises.

## Horizon Rules

- `Now` is for the highest-confidence, highest-leverage work.
- `Next` is for likely follow-on bets that depend on learning or sequencing.
- `Later` is for lower-confidence or later-timed bets that should remain explicit but not overcommitted.

## Good Roadmap Characteristics

- every initiative links back to a goal or outcome
- customer-needs linkage stays visible
- uncertainty is explicit instead of hidden behind dates
- horizon placement can be explained
