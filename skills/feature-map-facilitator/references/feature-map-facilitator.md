# Feature Map Facilitator

Facilitate a live feature-mapping session with seeded prompts for actors, rules, examples, steps, outcomes, and questions.

## Use When

- the team is running a collaborative discovery session
- multiple people need to contribute to one shared feature board
- the goal is to expose disagreements or missing examples early

## Facilitation Prompts

- Which actor owns the hardest path through this feature?
- Which rule is business-critical versus just UI guidance?
- Which example proves the rule really holds?
- What outcome matters if the feature succeeds or fails?

## Good Output Characteristics

- prompts are built into the artifact instead of living only in meeting notes
- unresolved questions are visible before implementation starts
- the board can be refined into acceptance criteria or examples later
