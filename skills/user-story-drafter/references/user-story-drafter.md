# User Story Drafter

Draft the story in the selected syntax, then strengthen it.

## Drafting Rules

- Keep the story small enough that splitting decisions remain visible.
- Make the user outcome or measurable result explicit.
- Move hidden uncertainty into `open_questions` instead of stuffing it into the story text.
- Add only enough readiness detail to help INVEST, example mapping, or subtasking.

## Typical Downstream Handoffs

- `invest-readiness-checker`
- `example-map-builder`
- `story-splitting-method-selector`
- `story-subtask-planner`
