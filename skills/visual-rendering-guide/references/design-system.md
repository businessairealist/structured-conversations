# Design System

## Purpose

This file is the single source of truth for all visual styling in structured conversation artifacts. Every HTML page or Mermaid diagram generated by a skill must follow these standards.

## Visual Family Mapping

Different artifact types use intentionally different visual families. Do not collapse all outputs into one generic palette.

| Artifact type | Visual family | Primary palette | Use for |
|---|---|---|---|
| Architecture / Board pages | Warm earth | Terracotta + sage | Empathy maps, journey maps, story maps, roadmaps, OKR maps, feature maps, example maps, boards |
| Mermaid flowcharts / trees | Cool process | Teal + cyan | Impact maps, hypothesis trees, opportunity-solution trees, process flows, value stream maps |
| Data tables / matrices | Analytical | Rose + cranberry | Severity classifiers, comparison matrices, scoring rubrics, rule-example tables, INVEST checks |

## Theme Token System

## Typography

Use distinctive font pairings. Do not use Inter, Roboto, Arial, or system-only stacks as the primary brand typography.

### Recommended pairings

**Board / Architecture family:**
```css
--font-display: 'DM Serif Display', 'Georgia', serif;
--font-body: 'DM Sans', 'Helvetica Neue', sans-serif;
--font-mono: 'JetBrains Mono', 'Fira Code', monospace;
```

**Mermaid / Flow family:**
```css
--font-display: 'Space Grotesk', 'Helvetica Neue', sans-serif;
--font-body: 'Space Grotesk', 'Helvetica Neue', sans-serif;
--font-mono: 'Space Mono', 'Fira Code', monospace;
```

**Table / Analytical family:**
```css
--font-display: 'Source Serif 4', 'Georgia', serif;
--font-body: 'Source Sans 3', 'Helvetica Neue', sans-serif;
--font-mono: 'Source Code Pro', 'Fira Code', monospace;
```

### Loading fonts

When generating HTML, include Google Fonts via `<link>` in the `<head>`:

```html
<!-- Board family -->
<link href="https://fonts.googleapis.com/css2?family=DM+Sans:wght@400;500;700&family=DM+Serif+Display&family=JetBrains+Mono:wght@400;500&display=swap" rel="stylesheet">

<!-- Flow family -->
<link href="https://fonts.googleapis.com/css2?family=Space+Grotesk:wght@400;500;700&family=Space+Mono:wght@400;700&display=swap" rel="stylesheet">

<!-- Table family -->
<link href="https://fonts.googleapis.com/css2?family=Source+Sans+3:wght@400;600;700&family=Source+Serif+4:wght@400;600;700&family=Source+Code+Pro:wght@400;500&display=swap" rel="stylesheet">
```

### Labels and metadata

Use the mono font at small size with letter-spacing for labels, tags, and metadata:

```css
.label, .tag, .meta {
  font-family: var(--font-mono);
  font-size: 0.75rem;
  letter-spacing: 0.05em;
  text-transform: uppercase;
  color: var(--text-muted);
}
```

## Surface, Depth, and Background

### Background treatment

Avoid flat single-color canvases. Apply a subtle visual atmosphere using a dot grid:

```css
body {
  background-color: var(--bg);
  background-image: radial-gradient(var(--border-dim) 1px, transparent 1px);
  background-size: 20px 20px;
}
```

Or a subtle radial glow behind the main content:

```css
body::before {
  content: '';
  position: fixed;
  top: 20%;
  left: 50%;
  transform: translateX(-50%);
  width: 60vw;
  height: 40vh;
  background: radial-gradient(ellipse, var(--accent-primary-dim), transparent 70%);
  opacity: 0.06;
  pointer-events: none;
  z-index: -1;
}
```

### Depth tiers

Use three depth tiers consistently:

| Tier | Use | CSS |
|---|---|---|
| Hero / elevated | Primary insight cards, key findings, headings | `background: var(--surface-raised); box-shadow: var(--shadow-md); border-radius: 12px;` |
| Default | Standard cards, content sections | `background: var(--surface); box-shadow: var(--shadow-sm); border-radius: 8px;` |
| Recessed | Metadata, secondary details, code blocks | `background: var(--surface-recessed); border-radius: 6px;` |

**Squint test:** when you squint at the page, hero sections should be clearly dominant, default sections readable, and recessed sections visually subordinate.

## Layout Resilience and Overflow

### Flex/grid safety

Every flex or grid child must support shrink to prevent overflow:

```css
.flex-child, .grid-child {
  min-width: 0;
  overflow-wrap: break-word;
}
```

### Scrollable containers

Wide tables or diagrams must be horizontally scrollable:

```css
.table-container, .diagram-container {
  overflow-x: auto;
  -webkit-overflow-scrolling: touch;
}
```

### List safety

Never apply `display: flex` directly to `<ul>` or `<ol>` elements — this breaks list markers. Wrap list items in a flex container instead:

```css
/* Wrong — breaks bullet markers */
ul { display: flex; }

/* Right — preserves markers */
ul { list-style: disc inside; }
.list-grid { display: flex; flex-wrap: wrap; gap: 1rem; }
```

## HTML Page Template

Every generated HTML page should follow this skeleton:

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>[Artifact Title]</title>
  <!-- Font loading for the appropriate family -->
  <link href="[Google Fonts URL for family]" rel="stylesheet">
  <style>
    /* Theme tokens from the appropriate family */
    :root { ... }
    @media (prefers-color-scheme: dark) { :root { ... } }

    /* Base styles */
    *, *::before, *::after { box-sizing: border-box; margin: 0; padding: 0; }
    body {
      font-family: var(--font-body);
      color: var(--text);
      background-color: var(--bg);
      background-image: radial-gradient(var(--border-dim) 1px, transparent 1px);
      background-size: 20px 20px;
      line-height: 1.6;
      padding: 2rem;
    }
    h1, h2, h3 { font-family: var(--font-display); }

    /* Reduced motion */
    @media (prefers-reduced-motion: reduce) {
      *, *::before, *::after {
        animation-duration: 0.01ms !important;
        transition-duration: 0.01ms !important;
      }
    }

    /* Additional styles per artifact type */
  </style>
</head>
<body>
  <!-- Artifact content -->
</body>
</html>
```

## Choosing the Right Family

When generating visual output, select the family based on the artifact type:

1. **Is it a board, canvas, or poster layout?** → Board / Architecture (terracotta + sage)
2. **Is it a directed graph, tree, or process flow?** → Mermaid / Flow (teal + cyan)
3. **Is it a comparison table, scoring matrix, or data grid?** → Table / Analytical (rose + cranberry)

If an artifact mixes types (e.g., a board with an embedded data table), use the dominant family for the page and apply the secondary family's accent colors for the embedded element.
